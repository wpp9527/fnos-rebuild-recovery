# DNF Admin Pro - 项目需求文档

## 一句话需求
构建一个整合型 DNF 游戏管理后台，支持 GM 管理、PVF 解析、PVE 控制，部署在同一台虚拟机上。

## 功能需求

### P0 - 核心功能（必须）
1. **GM 邮件系统** - 发送邮件（文字+物品+金币），支持群发
2. **GM 物品操作** - 从 PVF 搜索物品并发送给角色
3. **GM 货币操作** - 充值金币/点券/代币
4. **PVF 解析** - Web 端解析 PVF 文件，搜索物品/装备/技能
5. **账号查询** - 搜索账号，查看角色列表
6. **角色查询** - 查看角色详细信息、物品、属性
7. **用户认证** - 用户名密码登录，JWT Token

### P1 - 重要功能（应该有）
8. **活动管理** - 启动/关闭游戏活动
9. **封号管理** - 封号/解封，封号原因记录
10. **审计日志** - 所有 GM 操作记录
11. **在线监控** - 查看在线玩家和角色
12. **角色操作** - 设置等级、重置疲劳、解锁背包

### P2 - 增强功能（可以有）
13. **PVE 管理** - SSH/API 连接 PVE，管理服务
14. **批量操作** - 批量发送物品/邮件
15. **邮件模板** - 预设邮件模板
16. **数据统计** - 玩家数据、物品分布统计

## 非功能需求

### 性能
- 查询响应时间 < 500ms
- PVF 搜索 < 100ms
- 支持 100 并发用户

### 安全
- 所有写操作需认证
- GM 操作需审计日志
- 敏感操作需二次确认
- 数据库使用只读账号（查询）

### 可用性
- Web 界面友好
- 支持中文
- 响应式设计

### 部署
- Docker Compose 一键部署
- 与现有 DNF 服务器同机
- 数据持久化

## 技术约束

### 必须使用
- Go (后端主服务)
- Python (PVF 解析服务)
- MySQL 5.7 (现有数据库)
- Docker Compose (部署)

### 参考项目
- Zageku/DNF_pvf_python - PVF 解析逻辑
- onlyGuo/dnf-server - GM 功能参考
- dnf-public-admin - 现有框架

## 验收标准

### 功能验收
1. 能登录后台
2. 能搜索账号和角色
3. 能从 PVF 搜索物品
4. 能发送邮件和物品
5. 能充值金币/点券
6. 能启动/关闭活动
7. 能封号/解封

### 技术验收
1. 所有 API 有单元测试
2. 前端页面可正常访问
3. Docker Compose 能一键启动
4. 无安全漏洞

## 项目结构

```
├── backend/          # Go 后端
│   ├── cmd/          # 入口
│   ├── internal/     # 内部包
│   │   ├── auth/     # 认证
│   │   ├── account/  # 账号
│   │   ├── character/# 角色

│   │   ├── pvf/      # PVF 解析
│   │   ├── activity/ # 活动
│   │   ├── audit/    # 审计
│   │   ├── pve/      # PVE 连接
│   │   └── httpapi/  # HTTP 路由
│   └── go.mod
├── pvf-service/      # Python PVF 服务
│   ├── app.py
│   └── requirements.txt
├── frontend/         # Vue 前端
│   ├── src/
│   └── package.json
├── deploy/           # 部署配置
│   ├── docker-compose.yml
│   └── nginx.conf
├── docs/             # 文档
└── tests/            # 测试
```
