# PVF 界面重设计方案

## 参考设计模式

### 1. 左侧分类树 + 右侧内容区（类似 Element Admin）
```
┌─────────────────────────────────────────────────────────────┐
│  搜索栏: [搜索物品名/ID...] [分类▼] [等级▼] [搜索]          │
├──────────┬──────────────────────────────────────────────────┤
│ 全部分类 │  物品列表表格                                     │
│ ├ 武器   │  ┌────┬────────┬──────┬────┬────┐                │
│ │ ├ 剑   │  │名称│ ID     │ 类型 │等级│操作│                │
│ │ ├ 刀   │  ├────┼────────┼──────┼────┼────┤                │
│ │ └ 弓   │  │... │ ...    │ ...  │... │详细│                │
│ ├ 防具   │  └────┴────────┴──────┴────┴────┘                │
│ │ ├ 头盔 │                                                  │
│ │ ├ 铠甲 │  分页: [< 1 2 3 ... 100 >]  共 83977 件         │
│ │ └ 靴子 │                                                  │
│ ├ 首饰   ├──────────────────────────────────────────────────┤
│ ├ 称号   │  物品详情面板                                     │
│ ├ 宠物   │  名称: xxx                                       │
│ ├ 消耗品 │  ID: xxx                                         │
│ ├ 材料   │  类型: xxx                                       │
│ ├ 任务   │  [发放] [邮件] [查看JSON]                         │
│ └ 其他   │                                                  │
└──────────┴──────────────────────────────────────────────────┘
```

### 2. 关键交互
- 分类树支持展开/折叠
- 点击分类自动筛选
- 搜索支持实时防抖
- 表格支持排序
- 分页支持跳转指定页
- 物品行点击显示详情

### 3. 配色方案
- 主色: #1890ff (Ant Design 蓝)
- 分类树背景: #fafafa
- 选中高亮: #e6f7ff
- 表格斑马纹: #f5f5f5
