3. **物品查询** - 通过SSH读取远程PVF文件 (`/opt/dnf-llnut/data/conf.d/dnf-console/source/gold.txt`)

- **装备查询**: 优先PVF → 失败则查 `taiwan_cain_web.dnf_item_info`

- `taiwan_cain_2nd.user_items` - 角色背包
- `taiwan_cain_2nd.skill` - 角色技能 (skill_slot blob)
- `taiwan_cain_web.skill_info` - 技能定义
- `taiwan_cain_web.dnf_item_info` - 物品信息

## 飞牛影视 GPU 转码问题排查 (02:38)

### 问题
- 飞牛影视播放时显示 "当前gpu繁忙 硬件转码失败 无法播放"

### 根本原因
1. **NVIDIA 驱动版本不匹配**
   - 内核模块版本: 580.142 (飞牛云 alternatives 目录提供)
   - NVML 库版本: 580.126.20 (Debian 包)
   - 错误: `Driver/library version mismatch`

2. **Tesla P4 需要 580.xx Legacy 驱动**
   - 当前安装的是 595.71.05 (不支持 P4)
   - 降级到 580.126.20 (Debian 可用版本)
   - 但飞牛云内核自带的是 580.142 (不匹配)

3. **缺少 NVIDIA DRI 驱动**
   - `/usr/trim/lib/mediasrv/lib/dri/` 中没有 NVIDIA 驱动
   - 只有 Intel、AMD、Radeon 驱动

4. **Ollama 无法使用 GPU**
   - 没有正确加载 NVIDIA 内核模块
   - `nvidia-smi` 报错 Driver/library version mismatch

### 已执行操作
1. 卸载 595 版本驱动
2. 安装 580.126.20 版本驱动
3. 修改飞牛影视配置禁用 GPU 转码 (`/usr/trim/etc/mediasrv.conf`)
4. 重启 trim-media 和 mediasrv 服务

### 当前状态
- ❌ NVIDIA 驱动仍未正常工作 (版本不匹配)
- ✅ 飞牛影视已切换到 CPU 转码
- ❌ Ollama 无法使用 GPU

### 关键文件
- 飞牛影视配置: `/usr/trim/etc/mediasrv.conf`
- NVIDIA 驱动 alternatives: 飞牛云定制内核提供的 580.142
- DRI 驱动目录: `/usr/trim/lib/mediasrv/lib/dri/`

### 解决方向
1. 需要找到 580.142 版本的 NVML 库 (与飞牛云内核模块匹配)
2. 或者联系飞牛云官方获取正确的驱动包
3. 或者回退到 CPU 转码方案

1. **背包物品名称** - 从 `taiwan_cain_web.dnf_item_info` 表查询装备名称
2. **角色技能显示** - 解析 `skill` 表的 `skill_slot` blob (zlib压缩)
3. **物品查询** - 通过SSH读取远程PVF文件 (`/opt/dnf-llnut/data/conf.d/dnf-console/source/gold.txt`)
4. **技能按职业区分** - 基础职业→转职选择

### 技术要点
- **DB连接**: `charset='latin1'`, `use_unicode=False` 处理双重UTF-8编码
- **PVF加载**: 通过SSH读取远程文件，缓存5分钟
- **技能blob解析**: zlib解压 → 每2字节(索引+等级) → 查skill_info表
- **装备查询**: 优先PVF → 失败则查 `taiwan_cain_web.dnf_item_info`

### 关键数据库表
- `taiwan_cain.charac_info` - 角色信息
- `taiwan_cain_2nd.user_items` - 角色背包
- `taiwan_cain_2nd.skill` - 角色技能 (skill_slot blob)
- `taiwan_cain_web.skill_info` - 技能定义
- `taiwan_cain_web.dnf_item_info` - 物品信息
