## 经验教训 (18:27)

### AzerothCore 编译踩坑记录
1. **VM 105 编译失败**: GCC 和 Clang 都出现段错误，可能是内存不足或编译器不稳定
2. **PVE 主机编译失败**: CMake 生成步骤出错，`src/server/database/CMakeLists.txt` 中的安装过程不完整
3. **Docker Hub 访问问题**: VM 105 无法拉取 Docker 镜像，TLS 握手超时，即使配置了代理
4. **MariaDB 不兼容**: AzerothCore 需要 MySQL 8.0+ 特性，MariaDB 无法使用
5. **SQL 版本不匹配**: 从 NAS repack 导入的数据库与编译的 AzerothCore 版本不一致

### 解决方案
1. **使用 Docker 编译**: 在 PVE 主机上使用 Docker 容器编译，避免环境问题
2. **MySQL 8.0 Docker**: 使用 Docker 容器运行 MySQL 8.0，避免兼容性问题
3. **配置文件精简**: 使用最小化配置，避免配置错误导致启动失败
