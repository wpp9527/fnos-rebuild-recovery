## DNF Admin v3.1 优化 (23:10)

### 修复用户反馈问题

**问题1: 技能没有描述**
- 原因: 技能描述字段使用Big5编码存储
- 修复: 使用 `value.decode('big5')` 或 `value.decode('cp950')` 解码
- 结果: ✅ 技能描述正确显示中文

**问题2: PVF解析不能翻页**
- 原因: 前端没有翻页功能
- 修复: 添加 `pvfPage`, `pvfPageSize`, `pvfTotal` 状态变量和 `renderPVFPagination()` 函数
- 结果: ✅ 支持上一页/下一页，每页50条

**问题3: 角色背包物品没有名称**
- 原因: 背包物品ID (105550516等) 不在物品表中
- 修复: 从 `dnf_item_info` 表查询名称，无名称时显示 `槽位名-ID`
- 结果: ✅ 显示 "武器-105550516" 格式

### 编码说明

| 字段 | 编码 | 解码方式 |
|------|------|----------|
| 物品名称 | UTF-8 | `value.decode('utf-8')` |
| 技能描述 | Big5 | `value.decode('big5')` |
| 角色名称 | UTF-8 | `value.decode('utf-8')` |
| 怪物名称 | UTF-8 | `value.decode('utf-8')` |

## DNF Admin v3.2 - GM管理功能 (23:30)

### 新增GM管理功能

参考旧后台 `dnf-server-web-public` 的GM功能，添加以下API：

| 功能 | 方法 | 端点 | 说明 |
|------|------|------|------|
| 保存公告 | POST | `/api/v2/gm/notice/save` | 保存登录器公告 |
| 获取公告 | GET | `/api/v2/gm/notice` | 获取公告内容 |
| 发送物品 | POST | `/api/v2/gm/send-item` | 发送物品到角色，支持强化等级 |
| 设置等级 | POST | `/api/v2/gm/set-level` | 直接设置角色等级 |
| 添加金币 | POST | `/api/v2/gm/add-gold` | 为角色添加金币 |
| 踢出用户 | POST | `/api/v2/gm/kick` | 强制踢出在线用户 |
| 封禁用户 | POST | `/api/v2/gm/ban` | 封禁违规用户 |
| 解封用户 | POST | `/api/v2/gm/unban` | 解除用户封禁 |
| 充值 | POST | `/api/v2/gm/recharge` | 为用户充值点券 |

### 前端GM管理界面

- 公告管理: 文本区域保存公告
- GM命令: 发送物品、设置等级、添加金币
- 用户管理: 踢出、封禁、解封用户
- 充值管理: 为用户充值点券
