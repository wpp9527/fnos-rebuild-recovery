## PVF文件来源和加密方式

### 关键发现
1. **PVF文件是预置的**，不是由网关生成的
   - 日志显示: "Script.pvf have already inited, do nothing!"
   - 文件位置: `/data/Script.pvf` (170MB)
   - 修改时间: Apr 30 03:12 (镜像内置)

2. **网关使用TEA加密** (不是AES!)
   - TeaEncrypt.go 显示使用 **TEA (Tiny Encryption Algorithm)**
   - 密钥: `troqkddmtroqkcdm` (16字节)
   - 密码加密串: `uu5!^%jg`
   - 后缀: `e8b10c1f8bc3595be8b10c1f8bc3595b`

3. **数据库密码解密**
   - game pwd key: `20e35501e56fcedbe8b10c1f8bc3595be8b10c1f8bc3595b`
   - game password: `uu5!^%jg`

### DNF 环境变量
- GATE_AES_KEY: `a1b2c3d4e5f6789012345678901234567890abcdef0123456789abcdef012345`
- DNF_DB_GAME_PASSWORD: `uu5!^%jg`
- GATE_BIND_ADDRESS: `0.0.0.0:5505`
- INITIAL_CERA: 1000

### 结论
- PVF文件是镜像内置的，不是运行时生成的
- PVF文件可能是用TEA加密的
- 需要找到PVF解密工具或方法

## PVF数据导出成功

### 关键发现
- 数据库字符集是latin1，但数据实际是UTF-8
- mysql客户端需要用 `--default-character-set=latin1` 读取
- Python用 `result.stdout.decode("utf-8")` 解码得到正确中文
- JSON中 `type` 字段需要兼容int和string类型

### 最终数据
- 物品总数: 83965个
- 分类: 装备8288, 消耗品13406, 材料6745, 副职业15400, 任务416, 时装1236, 其他38474
- 稀有度: 普通37256, 高级3762, 稀有15332, 神器4826, 传说3075, 史诗19713

### 修复内容
1. Go后端 `pvf/service.go` - Type字段支持int/string两种类型
2. 数据库连接字符集改为 `latin1`
3. PVF数据文件从50000增加到83965个物品

## 物品名称解析修复

### 关键公式
- `FLOOR(it_id / 100000)` = `it_no` (在 `dnf_item_info` 表中)
- 例: `it_id = 105550516` → `1055` → "有機草莓"
- 例: `it_id = 264950000` → `26495` → "勇者歸來"

### 背包查询SQL
```sql
SELECT ui.slot, ui.it_id, FLOOR(ui.it_id/100000) as item_no,
       ii.it_name, ii.rarity, ii.master_type, ii.sub_type
FROM taiwan_cain_2nd.user_items ui
LEFT JOIN taiwan_cain_web.dnf_item_info ii ON FLOOR(ui.it_id/100000) = ii.it_no
WHERE ui.charac_no = 1
```

### 测试结果
- 角色 "6666" (c_no=1): 22个物品，19个有機草莓，2个哥布林塵埃，1个蘿卜咸菜
- 勇者歸來 (it_no=26495) 不在当前角色背包中

### Go后端修复
- `character/service.go` - 物品查询SQL修复
- `pvf/service.go` - Type字段支持int/string

### 数据库字符集
- MySQL容器使用latin1字符集，但存储的是UTF-8数据
- DSN配置: `charset=latin1` (不是utf8mb4)
- mysql客户端: `--default-character-set=latin1`，Python `stdout.decode("utf-8")`
