# 🌐 网络架构

## 拓扑

```
互联网 → 192.168.1.1 (主路由/Lucky反代:5000)
              ↓
    192.168.1.190 (PVE 服务器)
        ├── 192.168.1.212 (FNOS 飞牛云 NAS) ← OpenClaw 本机
        └── 192.168.1.213 (代理容器 :7890)
```

## 设备清单

| 地址 | 角色 | 备注 |
|------|------|------|
| 192.168.1.1 | 主路由 | Lucky 反代，端口 5000 处理所有网页反代 |
| 192.168.1.190 | PVE 服务器 | 虚拟化宿主 |
| 192.168.1.212 | FNOS (本机) | 飞牛云 NAS，OpenClaw 所在 |
| 192.168.1.213 | 代理容器 | 端口 7890 |

## 端口映射

| 外部 | 内部 | 服务 |
|------|------|------|
| openclaw.19930901.xyz:5000 | 192.168.1.212:18789 | OpenClaw Gateway |
| fnos.19930901.xyz:5000 | TRIM nginx | FNOS 管理面板 |

## DNS / 域名

- `*.19930901.xyz` → 主路由 192.168.1.1 (Lucky 分发)
- CPA API: `cpi.19930901.xyz:5000`

## 网络注意事项

- Lucky 反代从 192.168.1.1 转发到内网服务
- OpenClaw trustedProxies 已配置: 127.0.0.1, ::1, 192.168.1.0/24, 172.16.0.0/12
- Control UI allowedOrigins 需包含外网域名
