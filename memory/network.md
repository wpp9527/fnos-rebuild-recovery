### Tailscale 网络配置

- **FNOS**: 100.90.163.108
- **VM105 (wow-server)**: 100.115.4.113
- **Windows 设备**: 100.113.63.109

### 国外连接方式

1. 在国外设备上安装 Tailscale
2. 使用相同账号登录 Tailscale
3. 编辑 `realmlist.wtf` 文件：
   ```
   set realmlist 100.115.4.113
   ```
4. 启动客户端连接

### 端口转发配置（备用）

如果 Tailscale 不可用，可以在 Lucky 反代 (192.168.1.1) 上配置端口转发：
- 端口 3724 (TCP) → 192.168.1.119:3724
- 端口 8085 (TCP) → 192.168.1.119:8085

## 网络注意事项

- Lucky 反代从 192.168.1.1 转发到内网服务
- OpenClaw trustedProxies 已配置: 127.0.0.1, ::1, 192.168.1.0/24, 172.16.0.0/12
- Control UI allowedOrigins 需包含外网域名
