## imagesrv 服务问题

### 问题描述
- `imagesrv` 服务因库兼容性问题无法启动
- `libgdal.so.32` 需要 `libmysqlclient_18` 版本符号
- 当前系统 MariaDB 10.11 只提供 `libmysqlclient_21.0`
- 服务不断重启（已重启 69+ 次）

### 尝试的修复方法
1. ✗ 创建兼容性库 (`libmysqlclient_18.so`)
2. ✗ 使用 `patchelf` 添加版本符号
3. ✗ 使用 `objcopy` 添加版本符号
4. ✗ 使用 `LD_PRELOAD` 加载兼容性库

### 解决方案
- 等待 FNOS 官方修复库兼容性问题
- 或者降级 MariaDB 到提供 `libmysqlclient_18` 的版本
